## Руководство по минимальному использованию Git.

Для начала нужно [установить](https://github.com/git-for-windows/git/releases/download/v2.56.0.windows.3/Git-2.56.0.3-64-bit.exe) сам Git.

После установки нужно открыть консоль (cmd) или PowerShell. После открытия, прописать:

```
git config --global user.name "ваш юз с гита"
```
```
git config --global user.email ваш_емаил_с_гита
```

### Супер! Первоначальная настройка выполнена.

После открываем консоль в нужной вам папке, либо переходим в нужную папку с помощью команды `cd`.

В нужной папке выполняем:
```
git clone https://github.com/exexeeeex/fix-bot.git
```
После того, как репозиторий скопируется, выполняем:
```
cd ./fix-bot
```
Мы оказались в папке проекта, следующим шагом нам нужно проверить, на какой ветке мы находимся. Выполняем:
```
git branch
```
Если ветка `dev` - супер! Иначе выполняем:
```
git checkout dev
```
После изменения ветки выполняем
```
git pull
```
Данная команда позволит нам подтянуть самые последние изменения.

## Что делать с полученными файлами?

1. Заменяем или добавляем полученные файлы.
2. Выполняем в консоли:
```
git add .
```
```
git commit -m "Описание, которое я отправлю вам вместе с файлами
```
```
git push
```
3. Ожидаем, пока я приму запрос на добавление.
